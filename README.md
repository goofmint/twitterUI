# twitterUI

2010〜2011年頃の twitter.com（New Twitter）を、見た目と主要操作まで再現した非公式デモです。公式製品ではありません。

公開プロフィールは当時の @jack ページ（茶色の背景と鳥、Sign Up バナー、右カラム）を参考にしています。ロゴは当時の wordmark を使用しています。

## 動かす

```bash
npm install
npm run dev
```

## できること

- ログアウト時の公開プロフィール（参考画像の構成）
- Sign in / Sign up（デモ用。ユーザー名とパスワードを入れれば入れます）
- 2010年のホーム（What's happening?、140字、Favorite は星）
- プロフィール / Messages / Who To Follow
