# twitterUI

2023年前半（X更名前）の twitter.com ホーム画面を、見た目と主要操作まで再現した非公式デモです。公式製品ではありません。

## 動かす

```bash
npm install
npm run dev
```

## できること

- 3カラム（左ナビ / タイムライン / 右サイドバー）とモバイル下タブ
- おすすめ / フォロー中
- ツイート投稿（280字リング）
- いいね・リツイート・フォロー
- 表示: デフォルト / ダークブルー / ライトアウト

アイコンは shadcn/ui と同じ Lucide（`lucide-react`）です。青い鳥ロゴだけインラインSVGです。
